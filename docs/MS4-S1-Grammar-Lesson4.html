02 UNDERSTAND THE MEANING ⭐ EASY

🧠 Cause vs Effect

Before learning the connectors, we need to understand the difference between a cause and an effect.

🟠 CAUSE

WHY something happens

The weather was very cold.

➜

🟢 EFFECT

WHAT happens as a result

The tourists stayed inside.

Two ideas:

🟠 The weather was very cold.
🟢 The tourists stayed inside.

Connected sentence:

The tourists stayed inside because the weather was very cold.

OR

The weather was very cold, so the tourists stayed inside.
📘 الشرح بالعربية:

السبب (Cause) هو لماذا وقع الحدث.
النتيجة (Effect) هي ما حدث بسبب ذلك.

مثال:
كان الجو بارداً جداً ← السبب
بقي السياح في الداخل ← النتيجة

نستعمل أدوات الربط لتوضيح العلاقة بين السبب والنتيجة.

03 LEARN THE RULES ⭐⭐ LEARN

📜 The Seven Connectors

We use different connectors to introduce causes and effects.

🟠 Cause Connectors

BECAUSE · AS · SINCE

These connectors introduce a reason.

The museum is popular because it contains rare artefacts.
As the weather was rainy, the visitors stayed inside.
Since the monument is famous, many tourists visit it.

🟢 Effect Connectors

SO · THEREFORE · CONSEQUENTLY · AS A RESULT

These connectors introduce a result.

The monument is famous, so many people visit it.
The bridge was damaged. Therefore, it was closed.
The museum was renovated. As a result, more visitors came.

✨ Meet Each Connector

CAUSE

Because

Introduces a reason.

The tower is famous because it is very tall.

CAUSE

As

Introduces a reason. Often used at the beginning.

As the tower is famous, many tourists visit it.

CAUSE

Since

Introduces a reason.

Since the museum is interesting, many pupils visit it.

EFFECT

So

Introduces a result.

The museum was closed, so we went home.

EFFECT

Therefore

Introduces a result. Common in formal writing.

The road was blocked. Therefore, we changed our route.

EFFECT

Consequently

Introduces a result. Common in formal writing.

The monument was damaged. Consequently, it was closed.

EFFECT

As a Result

Introduces a result.

The museum became popular. As a result, more visitors came.

📚 Connector Reference Table

Connector Function Example

Since Cause Since it rained, we stayed home.

Therefore Effect It rained. Therefore, we stayed home.
Consequently Effect It rained. Consequently, we stayed home.

04 GRAMMAR TOOLKIT ⭐⭐ LEARN

⚠️ Word Order & Punctuation

Learn where to place each connector and how to use punctuation correctly.

🟠 Cause Connectors

Pattern 1:
EFFECT + because/as/since + CAUSE

The tourists stayed inside because it was raining.

Pattern 2:
Because/As/Since + CAUSE, + EFFECT

Because it was raining, the tourists stayed inside.

🟢 Effect Connectors

With SO:

CAUSE, so EFFECT

It was raining, so the tourists stayed inside.

With THEREFORE / CONSEQUENTLY / AS A RESULT:

CAUSE. Therefore, EFFECT.

It was raining. Therefore, the tourists stayed inside.
💡 Important punctuation:

Use a comma before so when joining two independent clauses.
Use a comma after an introductory because / as / since clause.
When therefore, consequently, or as a result begins a new sentence, use a full stop before it and a comma after it.

❌ Common Mistakes

Incorrect Correct
Because it rained, so we stayed home. Because it rained, we stayed home.
The road was closed because we took another route. The road was closed, so we took another route.
It rained, therefore we stayed home. It rained. Therefore, we stayed home.
As it was cold we stayed inside. As it was cold, we stayed inside.
The museum was closed. As a result we went home. The museum was closed. As a result, we went home.
⚠️ انتبه:

لا نستعمل Because و So معاً لربط نفس الجملتين.

❌ Because it rained, so we stayed home.

✅ Because it rained, we stayed home.

✅ It rained, so we stayed home.

09 WRITING WORKSHOP ⭐⭐⭐ CHALLENGE

✍️ Write About a Famous Landmark

Write a short descriptive paragraph about a famous landmark. Use cause-and-effect connectors to explain why it is important or popular.

🪜 Follow the Writing Steps

1️⃣ Introduce

Introduce the landmark and its location.

The Eiffel Tower is a famous landmark in Paris, France.

2️⃣ Explain

Give reasons using because, as or since.

It is popular because it is an important symbol of France.

3️⃣ Add Results

Use so, therefore, consequently or as a result.

It attracts many visitors. As a result, it is one of Paris's best-known attractions.

📝 Model Paragraph

The Eiffel Tower is a famous landmark in Paris, France. It attracts many tourists because it is an important symbol of the country. Since it offers beautiful views of Paris, many visitors enjoy going to the top. The tower is internationally famous. Therefore, it is one of the most recognisable landmarks in the world.
