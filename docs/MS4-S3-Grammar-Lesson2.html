STAGE TWO · NOTICE & LEARN

The Grammar Lab

Discover the two important conditional structures.

FORM 01 · POSSIBLE RESULT

If + Present, Will + Verb

We use this structure to talk about a possible future result of a condition.

IF + PRESENT SIMPLE
+
WILL + BASE VERB
If you revise regularly, you will improve.
If she studies hard, she will succeed.
If you don't prepare, you won't feel ready.
FORM 02 · DIRECT ADVICE

If + Present, Imperative

We use this structure to give advice, instructions, or recommendations.

IF + PRESENT SIMPLE
+
IMPERATIVE
If you want to succeed, revise regularly.
If you feel tired, take a short break.
If you want to concentrate, don't use your phone.
RULE 1 · Present Simple after IF
In ordinary first conditional sentences, we normally use the Present Simple after if, not will.

Incorrect: If you will study, you will succeed.
Correct: If you study, you will succeed.
RULE 2 · The imperative
Use the base form of the verb for positive advice: Study! Revise! Listen!
Use don't + base verb for negative advice: Don't waste time!
RULE 3 · Punctuation
When the if-clause comes first, put a comma after it.

If you practise, you will improve.
When the result comes first, a comma is usually unnecessary.
You will improve if you practise.
IMPORTANT · Prediction versus advice
If you revise, you will improve. predicts a possible result.

If you want to improve, revise. gives direct advice.

Both structures are useful, but they communicate different meanings.

الشرط من النوع الأول: نستعمله للحديث عن شرط ممكن الحدوث ونتيجته المحتملة في المستقبل.

الصيغة الأولى:
If + المضارع البسيط، will + الفعل في المصدر.

مثال:
If you study hard, you will succeed.
إذا درست بجد، فسوف تنجح.

الصيغة الثانية:
If + المضارع البسيط، فعل الأمر.

مثال:
If you want to succeed, study hard.
إذا أردت النجاح، ادرس بجد.

تذكّر: لا نستعمل عادةً will مباشرة بعد if في هذا النوع من الجمل.
