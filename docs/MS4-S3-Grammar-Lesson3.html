02

Important Grammar Notes

Pay attention to these useful details.

⚠️

ENJOY + -ING

After enjoy, use the -ing form.
❌ I enjoy to read.
✅ I enjoy reading.

💡

LIKE, LOVE, HATE and PREFER

These verbs can often be followed by either -ing or to + infinitive.
✅ I like reading.
✅ I like to read.
In this checkpoint, we practise the -ing form.

🧠

Remember the Third Person -s!

I enjoy reading.
She enjoys reading.
He dislikes waiting.
The main verb changes, but the following activity stays in the -ing form.

03

The -ing Spelling Laboratory

Discover four spelling patterns.

🟢

1. Simply add -ing

play → playing
read → reading
help → helping

✂️

2. Drop the final silent -e

make → making
write → writing
dance → dancing

🔁

3. Double the final consonant

run → running
sit → sitting
swim → swimming

🔄

4. Change -ie to -y

lie → lying
die → dying
tie → tying

📌 ملاحظة: لا نضاعف الحرف الأخير في جميع الأفعال. نضاعفه في بعض الأفعال القصيرة مثل run → running. وتوجد قواعد إضافية تتعلق بالنبر وعدد المقاطع.
